# Automated quantum software engineering
- 发表年份：2024
- 期刊出处：*Automated Software Engineering*
- 论文类型：前瞻性概念综述论文，无具体实验、数据集与实验结果

## 一、研究背景与核心问题
### 研究背景
量子计算硬件快速迭代，现已出现数百量子比特级处理器，在经典计算机难以求解的复杂问题上展现出巨大算力潜力；**量子软件工程（QSE, Quantum Software Engineering）** 作为配套支撑领域，核心目标是设计高性能量子算法与量子软件。

### 当前量子软件开发现存难点
1. 量子逻辑违背直观认知，人类难以理解与推演；
2. 量子算法开发学习门槛极高，所需知识体系与传统软件工程师完全不同；
3. 量子系统规模持续扩张，依靠传统量子汇编、基于单量子比特的底层人工推理方式不再具备可行性。

### 现有量子软件开发三类主流范式（范式间存在显著割裂鸿沟）
1. A1：依托特定量子硬件算力实现可落地计算任务
2. A2：基于成熟量子算法改造适配工业实际场景
3. A3：依托量子信息独有的计算特性，原创全新量子算法

### 本文核心工作
首次提出并完整定义**自动化量子软件工程（AQSE, Automated Quantum Software Engineering）** 概念框架，并系统性梳理该框架的可行落地路径。
> AQSE 官方定义：一套可针对任意给定应用场景，自动生成完整量子计算解决方案的通用框架。

全文从三大维度系统阐释 AQSE：必要性（Why）、核心内涵（What）、落地实现方案（How）。

## 二、为何需要 AQSE（AQSE: Why?）
本部分论证量子软件开发自动化的核心价值，梳理当前量子软件工程难以突破的固有痛点：
1. 量子力学逻辑反直觉，人工设计、调试成本极高；
2. 领域准入门槛高，开发者需掌握专属量子理论知识；
3. 量子系统指数级状态空间，人工全量测试几乎无法实现；
4. 变分类量子算法可解释性差，人工调参、验证难度大。

自动化 AQSE 的核心目标：降低量子计算开发准入门槛，使普通开发者无需精通量子力学理论，即可调用量子算力完成业务开发。

## 三、AQSE 是什么（AQSE: What?）
### 核心定义
AQSE 是一套面向应用场景、全自动生成量子计算完整解决方案的标准化框架。

### 1. 易用性设计要求
- 提供分层可视化交互界面：从低代码平台逐步演进至无代码开发平台（NCDP）；
- 问题描述层高度抽象，屏蔽底层量子硬件、量子逻辑细节，设计思路对标 AutoML 自动化机器学习框架。

### 2. 问题适用性自动评估能力
自动化生成量子方案的前置核心模块：自主判定待求解问题是否具备量子加速价值。
能力支撑要求：
- 深度掌握计算复杂度理论（BQP、NP 复杂度类、量子搜索算法特性等）；
- 多维度综合评估算力资源约束：运行时间、量子比特空间、计算精度等指标。

## 四、如何实现 AQSE（AQSE: How?）
拆解构建完整 AQSE 引擎所需分层组件、底层表示与两大核心技术路线：
1. **用户意图形式化转换层**
    将自然语言描述、无代码界面拖拽输入的业务需求，转化为标准化形式化问题规范。
2. **量子特性形式化表达工具**
    采用线性逻辑等数学工具对量子叠加、纠缠等独有特性进行严谨建模表达。
3. **量子解空间表示与搜索架构**
    基于证明网、抽象语法树（AST）表征候选量子程序解，构建元图结构的全局算法搜索空间。
4. 两大自动化技术路线对比
    - 路线1：自动程序搜索
      包含穷举搜索、进化优化算法、神经网络搜索、大语言模型（LLM）生成等方案；
    - 路线2：自动定理证明
      包含演绎逻辑证明、范畴论建模、概率化证明体系等方案。
5. 引擎内置约束机制
    在自动化生成流程中内嵌量子程序正确性形式化证明，同时兼容硬件噪声、资源开销等非功能性约束需求。

## 五、结论
1. AQSE 是大幅降低量子应用开发门槛的核心研究方向，领域发展需同步推进自动化技术研发与量子计算通识教育；
2. AQSE 属于多学科深度交叉的长期研究难题，相关探索将拓展通用智能系统能力边界；
3. 研究定位面向中长期通用量子计算，不局限于现阶段有噪声中等规模量子（NISQ）设备的短期工程问题。
